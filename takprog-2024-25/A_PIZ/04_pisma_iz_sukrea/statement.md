Какав би то фудбалер Тирке био да нема љубавних проблема, тек након што је стигао у Сукре на ИОИ (Истраживање офсајда у информатици). У данашње време без интернета и мобилних телефона, једини начин да контактира своју девојку у далекој Србији јесте слањем писма. Пут до Сукреа носи са собом разне пустоловине (јахање коња, пливање по Амазону, пењање уз лијане...) због чега је Тирке одлучио да у својем љубавном писму користи искључиво нуле и јединице, уместо слова (не жели сазнати шта би се десило уколико се писмо оштети, нека слова постану нечитљива и његова девојка га погрешно разуме).

<br>

Тиркетово писмо садржи бинарну реч $S$. Дефинишимо операцију над једном бинарном речју $S$ на следећи начин: нека је $N$ дужина $S$, изаберимо сегмент $[l, r]$ $(1 \leq l \leq r \leq N)$ и затим заменимо цео сегмент карактера од $l$ до $r$ са једним карактером који је $xor$ свих карактера на том сегменту, где $xor$ представља операцију битовске ексклузије. Прецизније, нека је реч пре опрерације била $S_1S_2\cdots S_N$ и нека је $c = S_l \text { xor } S_{l+1} \text { xor } \cdots \text { xor } S_r$, oнда $S$ постаје $S_1S_2\cdots S_{l-1} \ c \ S_{r+1}\cdots S_N$.

<br>

Пре него што Тирке своје писмо да малом Станоју да га пошаље за Србију, он мора прво проверити квалитет бинарне речи записане на њему. Наиме, квалитет бинарне речи дефинишемо као број различитих бинарних речи које можемо добити применом поменуте операције произвољнан број пута. Како тај број може бити веома велик (и потенцијално отићи у офсајд), Тиркета занима само остатак при дељењу броја различитих бинарних речи које можемо постићи са бројем $998244353$.

<br>

## Опис улаза

<br>

У првој и јединој линији стандардног улаза дата је бинарна реч $S$.

<br>

## Опис излаза

<br>

У првој и јединој линији стандардног излаза исписати тражени број из текста задатка.

<br>

## Пример 1

<br> 

### Улаз

<br>

```
1010
```

<br>

### Излаз

<br>

```
6
```

<br>

## Објашњење

<br> 

Све бинарне речи које можемо добити након примењивања операције произвољан број пута су $\{ 0, \ 00, \ 11, \ 101, \ 110, \ 1010 \}$, па је онда и решење једнако $6$.

<br>

## Ограничења 

<br>

- $1 \leq |S| \leq 300000$
- $S_i \in \{0, 1\}$

<br>

Tест примери су подељени у $7$ дисјунктних група:
- У тестовима вредним $5$ поена: $|S| \leq 5000$ и $S$ се састоји само од нула, тј. $S_i = 0$
- У тестовима вредним $10$ поена: $|S| \leq 10$
- У тестовима вредним $15$ поена: $|S| \leq 25$
- У тестовима вредним $20$ поена: $|S| \leq 5000$ и $S$ се састоји само од јединица, тј. $S_i = 1$
- У тестовима вредним $15$ поена: $|S| \leq 400$
- У тестовима вредним $15$ поена: $|S| \leq 5000$
- У тестовима вредним $20$ поена: без додатних ограничења.

<br>

## Напомена

<br>

Оператор ексклузивне дисјункције у Pascal-u је означен са  `xor`, док у C++ га записујемо помоћу симбола  `^`. Ова операција $x\ \text{xor} \ y​$ се за ненегативне целе бројеве $x,y​$ дефинише на следећи начин. Прво се бројеви запишу у бинарном запису. Уколико један број има мање цифара од другог, дописују му се водеће нуле све док не буду имали исти број бинарних цифара. Тако се добијају два низа бинарних цифара, означимо их са $a_1, \ldots, a_k​$ и $b_1, \ldots b_k​$. Затим се за сваку позицију $i \in {1, \ldots, k }​$ рачуна $c_i​$ помоћу следећих правила:

-   За $a_{i} = 0, b_{i} = 0$ важи $c_{i} = 0$
-   За $a_{i} = 0, b_{i} = 1$ важи $c_{i} = 1$
-   За $a_{i} = 1, b_{i} = 0$ важи $c_{i} = 1$
-   За $a_{i} = 1, b_{i} = 1$ важи $c_{i} = 0$

Низ бинарних цифара $c_1, \ldots, c_k$ (који можда има водеће нуле) је бинарни запис резултата, односно броја $x \ \text{xor} \ y$.
